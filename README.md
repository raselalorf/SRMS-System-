
## Project Description
The Student Record Management System (SRMS) is a Java-based application developed to manage student records efficiently.
The system allows users to add, update, delete, and store student data using object-oriented programming principles.

## Features
- Add, update, and delete student records
- Save and load student data from files
- Generate basic reports
- Exception handling for invalid inputs
- Organized using object-oriented programming (OOP)

## Technologies Used
- Java
- GitHub

## How to Run the Project
1. Open the project in a Java IDE such as IntelliJ or NetBeans.
2. Compile all `.java` files.
3. Run the main class to start the program.

## Team Collaboration
This project was developed collaboratively using GitHub.
Each team member worked on separate branches and commits were used to track changes and manage version control.
