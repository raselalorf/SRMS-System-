# SRMS-System-
## Project Description
This project is a Student Record Management System (SRMS) developed using Java.
It allows managing student records including adding, updating, deleting, and saving data to files.

## Features
- Add, update, and delete student records
- Save and load student data from files
- Generate basic reports
- Exception handling for invalid inputs
- Organized using Object-Oriented Programming principles

## Technologies Used
- Java
- GitHub

## How to Run the Project
1. Open the project in any Java IDE (such as IntelliJ or NetBeans).
2. Compile all `.java` files.
3. Run the main class to start the program.

## Repository Structure
- src/ : Java source code files
- README.md : Project documentation

## Team Collaboration
The project was developed collaboratively using GitHub.
Each team member worked on a separate branch and commits were used to track changes.
